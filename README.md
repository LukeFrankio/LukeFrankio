## projects that go hard

### [TakumCpp](https://github.com/LukeFrankio/TakumCpp)
**Logarithmic tapered floating-point arithmetic library** in pure C++23.
- Template-based implementation for N ≥ 12 bits
- Immutable values with NaR (Not-a-Real) handling
- Comprehensive test suite and validation

### [CiviWave-FEM](https://github.com/LukeFrankio/CiviWave-FEM)
**Finite Element Method simulation** engine.
- Written in C++ and Slang
- Advanced physics simulation capabilities

### [PongCpp](https://github.com/LukeFrankio/pongcpp)
**Path traced pong on the CPU** because why use the GPU when you can make your processor cry? 
- Full ray tracing on CPU (masochism but make it art)
- Physically accurate lighting (for PONG)

### [Homebrew Creator](https://github.com/LukeFrankio/Homebrew-Creator-CP--RED-)
Web-based tool for creating D&D/TTRPG homebrew content.
- Built with TypeScript and CSS

### [smolfib](https://github.com/LukeFrankio/smolfib)
A lightweight Fibonacci sequence generator/library in C++.
