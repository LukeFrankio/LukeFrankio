## Projects That Go Hard

### [TakumCpp](https://github.com/LukeFrankio/TakumCpp)

[![TakumCpp stars](https://img.shields.io/github/stars/LukeFrankio/TakumCpp?style=for-the-badge)](https://github.com/LukeFrankio/TakumCpp/stargazers)
[![TakumCpp last commit](https://img.shields.io/github/last-commit/LukeFrankio/TakumCpp?style=for-the-badge)](https://github.com/LukeFrankio/TakumCpp/commits)
[![TakumCpp language](https://img.shields.io/github/languages/top/LukeFrankio/TakumCpp?style=for-the-badge)](https://github.com/LukeFrankio/TakumCpp)

**logarithmic tapered floating-point arithmetic library** in modern C++.

why you should care: if you like weird number systems, high dynamic range, or making IEEE 754 cry, this is for you.

- template-based implementation for $N \ge 12$ bits
- immutable values with NaR (not-a-real) handling
- comprehensive test suite and validation

### [CiviWave-FEM](https://github.com/LukeFrankio/CiviWave-FEM)

[![CiviWave-FEM stars](https://img.shields.io/github/stars/LukeFrankio/CiviWave-FEM?style=for-the-badge)](https://github.com/LukeFrankio/CiviWave-FEM/stargazers)
[![CiviWave-FEM last commit](https://img.shields.io/github/last-commit/LukeFrankio/CiviWave-FEM?style=for-the-badge)](https://github.com/LukeFrankio/CiviWave-FEM/commits)
[![CiviWave-FEM language](https://img.shields.io/github/languages/top/LukeFrankio/CiviWave-FEM?style=for-the-badge)](https://github.com/LukeFrankio/CiviWave-FEM)

**finite element method simulation** engine.

why you should care: FEM is the "turn physics into a sparse linear system" pipeline, and i love building that pipeline.

- written in C++ and Slang
- advanced physics simulation capabilities

### [PongCpp](https://github.com/LukeFrankio/pongcpp)

[![PongCpp stars](https://img.shields.io/github/stars/LukeFrankio/pongcpp?style=for-the-badge)](https://github.com/LukeFrankio/pongcpp/stargazers)
[![PongCpp last commit](https://img.shields.io/github/last-commit/LukeFrankio/pongcpp?style=for-the-badge)](https://github.com/LukeFrankio/pongcpp/commits)
[![PongCpp language](https://img.shields.io/github/languages/top/LukeFrankio/pongcpp?style=for-the-badge)](https://github.com/LukeFrankio/pongcpp)

**path traced pong on the CPU** because why use the GPU when you can make your processor cry?

why you should care: it's a tiny game, but the rendering math is real (and painfully educational).

- full ray tracing on CPU (masochism but make it art)
- physically accurate lighting (for PONG)
